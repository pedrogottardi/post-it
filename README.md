# Post-it

App de lembretes simples, rápido e sem distrações para Android.

## Funcionalidades

- **Lembretes com data/hora** — Crie lembretes com data e hora específicas
- **Calendário visual** — Veja todos os lembretes do mês de uma vez
- **Notificações locais** — Alertas no horário certo, sem precisar de internet
- **Backup e Importar JSON** — Exporte e restaure seus dados facilmente
- **Sem anúncios, sem login, sem rastreamento** — Seus dados ficam no seu dispositivo

## Instalação

1. Baixe o APK acima
2. No Android, permita instalação de "Fontes desconhecidas"
3. Instale o APK

## Auto-atualização

O app verifica atualizações automaticamente ao abrir. Se houver nova versão, notifica e permite atualizar com um toque.

## Privacidade

- **Zero coleta de dados** — Nada é enviado para servidores
- **Armazenamento local** — Seus dados ficam apenas no seu aparelho
- **Código aberto** — Auditoria completa em [GitHub](https://github.com/pedrogottardi/post-it)
