# Post-it

Aplicativo de lembretes simples e elegante para Android.

## Funcionalidades

- 📝 Lembretes com título, descrição, data e hora
- 📅 Calendário visual mensal
- 🔔 Notificações locais
- 💾 Backup/Exportar/Importar JSON
- 🎨 Tema brutalista amarelo/preto
- 🔄 Auto-atualização via GitHub Releases

## Download

**[Baixar última versão (APK)](https://github.com/pedrogottardi/post-it/releases/latest/download/Post-It-1.0.0.apk)**

Ou acesse a página de download: **[https://pedrogottardi.github.io/post-it/](https://pedrogottardi.github.io/post-it/)**

## Instalação

1. Baixe o APK acima
2. No Android, permita instalação de "Fontes desconhecidas"
3. Instale o APK

## Auto-atualização

O app verifica atualizações automaticamente ao abrir. Se houver nova versão, notifica e permite atualizar com um toque.

## Desenvolvimento

```bash
# Instalar dependências
npm install

# Desenvolvimento
npm run dev

# Build para produção
npm run build

# Build APK
npm run apk
```

## Tecnologias

- **Next.js 14** + React 18
- **Capacitor** para Android
- **Tailwind CSS** para styling
- **TypeScript**
- **Vercel** para deploy da página de download
