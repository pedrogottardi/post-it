## ✨ Por que Post-it?

| Simplicidade | Privacidade | Confiabilidade |
| :---: | :---: | :---: |
| Interface limpa e intuitiva | Zero coleta de dados | Notificações locais precisas |
| Sem anúncios, sem login | Dados só no seu dispositivo | Backup/Restore via JSON |
| Foco no essencial | Funciona offline | Auto-atualização inteligente |

## 🔒 Privacidade em Primeiro Lugar

<div align="center">

| ✅ **O que FAZEMOS** | ❌ **O que NÃO FAZEMOS** |
| :--- | :--- |
| Armazenamos dados **localmente** no dispositivo | Enviamos dados para servidores externos |
| Usamos **notificações nativas** do Android | Exibimos anúncios ou rastreamos uso |
| Permitimos **exportar/importar** seus dados | Exigimos login, cadastro ou permissões desnecessárias |

</div>

> **Seus dados, suas regras.** O Post-it não possui backend, analytics, nem telemetria. Tudo fica no seu bolso.
